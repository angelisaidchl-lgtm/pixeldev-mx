CÓMO SUBIRLO:
1. Descarga y extrae el ZIP.
2. En GitHub, abre el repositorio pixeldev-mx.
3. Add file > Upload files y selecciona los archivos de la raíz.
4. Commit changes.

IMPORTANTE: GitHub móvil puede no permitir seleccionar carpetas ocultas. Para crear el formulario:
- En el repositorio pulsa Add file > Create new file.
- En el campo de nombre escribe exactamente:
  .github/ISSUE_TEMPLATE/enviar-recurso.yml
- Pega el contenido del archivo enviar-recurso.yml que se entrega por separado.
- Commit changes.
- En Settings > General revisa que Issues esté habilitado.

La página es estática. Las propuestas de la comunidad se envían por GitHub Issues y se revisan manualmente; no se permite subir archivos directamente al sitio.
