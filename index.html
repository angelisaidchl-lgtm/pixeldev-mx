      Aún no hay modelos publicados. Mientras tanto, prueba esta demostración propia hecha con CSS.

      Cómo agregar modelos reales

      • Crea una carpeta modelos en el repositorio y sube tus archivos (por ejemplo .glb). Solo modelos propios o con permiso.
      • La carpeta aparecerá en Recursos para abrirla o descargarla.
      • Una vista previa interactiva real necesita una biblioteca como <model-viewer>, que suma bastante peso (del orden de 1 MB o más). No se incluye para mantener el sitio ligero.

      Comunidad

      ¿Tienes un recurso que pueda ayudar a otras personas? Propónlo creando un Issue en GitHub (necesitas una cuenta gratuita).

      Todas las propuestas se revisan antes de publicarse. Desde esta web no se pueden subir archivos directamente: la propuesta se envía por GitHub y, si se aprueba, se agrega al repositorio.

      Proponer un recurso en GitHub

      Qué incluir en tu propuesta

      • Nombre y descripción corta del recurso.
      • Para qué sirve y en qué parte de Roblox Studio se usa.
      • Confirma que es tu creación o que tienes permiso para compartirla.
      • Un enlace al recurso, sin datos personales.

      Prepara tu propuesta

      Completa el formulario y se generará un borrador para abrir como Issue en GitHub. Esta página no guarda ni sube nada por sí sola.

      Tu propuesta todavía no se envió. Toca el botón para abrir el borrador en GitHub y confírmalo allí con “Submit new issue”. Se revisará antes de publicarse.

      Normas de la comunidad

      Respeto

      Trata bien a las demás personas. No se permite acoso, discriminación ni lenguaje ofensivo.

      Contenido propio

      Comparte solo lo que creaste o lo que tienes permiso de compartir. Respeta licencias y autoría.

      Seguridad

      No propongas scripts maliciosos, enlaces engañosos ni archivos que puedan dañar cuentas o dispositivos.

      Revisión

      Cada propuesta se revisa antes de publicarse. Puede rechazarse o pedirse que se corrija.

      Datos personales

      No publiques contraseñas, correos, teléfonos ni datos de otras personas, y menos de menores de edad.
